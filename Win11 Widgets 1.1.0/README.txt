Win11 Widgets 1.1.0 for Rainmeter
Author: ketamine
Based on Win10 Widgets by TJ Markham (http://win10widgets.com)
License: Creative Commons BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/)
Weather icons: Fluent Emoji (c) Microsoft, MIT license (see Weather\icons\CREDITS.txt)

Requirements: Rainmeter 4.5+, Windows 10/11 (Windows 11 recommended: uses Segoe Fluent Icons
and Segoe UI Variable fonts).

Install from source: copy this folder (without this README and RMSKIN.ini) to
  Documents\Rainmeter\Skins\Win11 Widgets
then in Rainmeter choose "Refresh all" and load widgets from the "Win11 Widgets" list.

Win11 Widgets is a remake of Win10 Widgets by TJ Markham.
See CHANGELOG.md for the introduction, credits and a full list of what was fixed and changed.
